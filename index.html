🎮 How to Play

1. Set up team names and add questions
2. Click answers or press 1-8 to reveal
3. Press X for wrong answers (3 strikes = steal)
4. Press W to award round points
5. Double-tap → for next round

🎤 Host Tips

• Use the host panel (bottom-right) for buttons
• Hide it when screen-sharing with audience
• Export questions to reuse them later
• Toggle sound with the 🔊 button (top-left)
